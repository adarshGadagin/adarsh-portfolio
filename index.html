Systems & Graphics

2D Graphics Editor in C

A desktop graphics editor built in C implementing foundational rasterization and geometry manipulation routines. Features interactive drawing of geometric primitives with stateful modification, selective deletion, dynamic redrawing, and file serialization.

  • Primitive Geometry: Implements line algorithms, rectangles, circles, and triangles with coordinate tracking.
  • State Management: In-memory structure maintaining active objects, supporting deletion and complete canvas redraws.
  • Persistence: Custom binary/text file save and load routines to store and reconstruct drawings.

Embedded Systems & IoT

Smart Door Access System

An embedded access control system built around an ESP32 microcontroller, integrating RFID-based credential verification, GPIO relay switching, and a solenoid lock mechanism. Engineered with fail-safe logic and stateful authorization checking.

  • RFID Authentication: Reads 13.56 MHz RFID tags via SPI bus, validating Unique Identifier (UID) payloads.
  • Relay Actuation: Optocoupled relay control triggering a 12V solenoid lock with automated re-lock timer.
  • Hardware Interfacing: Firmware written in C++ handling interrupt-driven events and debounced switching.
